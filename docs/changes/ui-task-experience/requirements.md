## 问题
改善部署操作员的界面体验，同时保证任务状态准确，避免停止后旧任务与新任务重叠。未提供实际使用频率或耗时数据。

## 方案
保留深色工作台，改善桌面布局和移动端切换，明确连接与任务状态，改进日志阅读与模型设置反馈。

## 场景
桌面同时查看终端和任务；手机切换面板；阅读历史日志；设置模型；停止任务后再次执行。

## 定下的事
- D1：桌面双面板、手机页签切换；切换不销毁正在运行的面板。
- D2：连接中、运行中、停止中、结束均有明确反馈；清理完成前不能再次启动。
- D3：工具错误不能直接结束界面上的任务状态；旧任务退出后才接受新任务。
- D4：日志分类、可折叠输出、暂停自动跟随、返回最新位置；限制浏览器保留日志的规模并明确提示截断。
- D5：独立设置弹窗，正确显示当前模型，显示加载/保存反馈并阻止重复提交。
- D6：组件卸载时关闭连接；终端随着面板尺寸变化重新计算行列数。

## 测试决定
前端状态和日志边界测试；Go WebSocket 任务控制回归；前端构建；桌面与手机尺寸的浏览器检查。
