# 单终端联动验证

2026-10-29，ui9。按用户“一个终端、Agent 运行时人工只参考”的要求实现。没有新增标签，没有改写 Agent 命令执行器。

## 行为

- 已配对终端的 WebSocket 以 JSON 文本帧接收 Agent 状态和执行事件，以二进制帧接收原人工 shell 输出。两类写入由同一互斥锁保护。
- Agent 获得任务槽位后，后台立即推送 running；取消进入 stopping；命令和审计清理结束后才推送 idle。工具 final 事件不能提前释放输入。
- 人工输入在前端禁用，并在服务器再次检查。运行/清理期间的输入直接丢弃，不排队到任务结束后执行。
- 终端打印真实命令、设备/启动位置、输出、退出码和耗时。右侧继续展示任务进度。终端内部保存独立的人工与 Agent 屏幕，始终只有一个可见；原人工会话及光标不被 Agent 的输出打乱。
- 结束后保留 Agent 输出供查看；再次输入时自动恢复原人工会话。两者没有共享 cd、环境变量或交互程序，不自动停止既有人工命令。
- 订阅队列有上限，慢客户端断开而非阻塞任务；重连获取当前控制状态，不重放断线期间的历史输出。
