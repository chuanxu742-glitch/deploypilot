## 改哪几个文件、每处怎么改
- web/src/App.tsx、index.css：深色工作台层级、桌面双栏、移动页签、配对提示。
- web/src/Terminal.tsx：连接状态、重连操作、容器尺寸监听；保持终端连接随页签切换存活。
- web/src/Agent.tsx：连接与任务状态、示例输入、日志分类、折叠、返回最新位置和受限缓存。
- web/src/Settings.tsx（提取）：原生对话框、模型初始值、异步反馈、避免重复提交。
- web/src/agent-state.ts 与测试：任务状态转换、日志合并及容量边界。
- web/tests/workspace.browser.cjs、web/package.json 和锁文件：保留可重跑的浏览器回归测试，Playwright 仅作开发依赖，自动启动并关闭本地预览。
- web/src/api.ts：共用 WebSocket 地址构造及会话认证入口。
- client/internal/server/agent.go 与测试：停止时保留运行占位，清理后通知空闲，明确通知运行中/停止中，限制写阻塞。
- client/internal/server/server.go：提供内部执行器工厂，回归测试可控制退出时机，不依赖网络和本机 Shell 探测速度。
- client/internal/llm/client.go 与测试（如需要）：任务持有配置快照，避免运行中设置与读取竞争。
- README.md：实际操作说明。
