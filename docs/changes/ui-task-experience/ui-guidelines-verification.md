# 界面修订验证

2026-10-29，基于主人在本会话提出的十项要求。实际用户为通过配对链接管理目标机器的部署操作员。

## 配色依据

依赖 `@radix-ui/colors` 3.0.0。依据 [Radix 色阶职责](https://www.radix-ui.com/colors/docs/palette-composition/understanding-the-scale) 和 [官方使用方法](https://www.radix-ui.com/colors/docs/overview/usage)：背景用 1–2，控件状态用 3–5，边框用 6–8，实心操作用 9–10，文字用 11–12。Slate 作为中性色，Mint 为操作和成功色，Red 为错误和停止，Amber 为等待及非成功结束。Mint 实心背景搭配深色文字。弹窗遮罩使用官方 black alpha。

终端背景、前景、光标、选择和标准 16 色使用官方 JavaScript 调色板。远程程序自行输出的真彩色与内容不属于应用界面文案，不改写用户命令或输出。

## 十项要求对应

| 要求 | 改动及检查 | 结果与局限 |
|---|---|---|
| 1 无中点分隔符 | 应用静态文案、启动标语扫描与测试；浏览器正文检查 | 通过。保留外部命令和模型返回的原始内容。 |
| 2 移除冗余解释 | 删除推广标语、装饰性英文、重复连接说明、终端装饰栏、输入区重复提示 | 已核对桌面、手机、弹窗截图；必要错误与配对操作保留。 |
| 3 文案准确简洁 | 改为“新建任务”“模型设置”“已保存”等功能用语，工具名称改为对应中文动词 | 人工结合实际控件位置核对；未做用户访谈，不声称所有人理解一致。 |
| 4 Radix 颜色与规范 | 官方 CSS 与 JS 调色板；浏览器核对应用可见元素文字和背景属于导入色阶 | 通过，终端主题也已覆盖。 |
| 5 对齐与嵌套圆角 | 面板标题图标中心误差不超过 1px；控件统一高度；页签与输入容器外圆角 8px、内控件 4px、内边距 4px | 自动对齐检查与截图核对通过；光学效果仍包含人工判断。 |
| 6 0.5px 边框 | `--line: 0.5px` 覆盖布局边框与聚焦轮廓，静态测试禁止其他边框宽度 | 通过；实际物理像素呈现受设备像素比影响。 |
| 7 减少动效 | 移除应用动画、过渡、阴影与渐变，终端关闭光标闪烁 | 静态检查通过，不对远程程序主动绘制的内容作修改。 |
| 8 字号约束 | 12/14/18px 三档；终端 14px；源码与实际渲染字体检查 | 通过，未发现小于 12px 的应用可见文字。 |
| 9 信息优先级与减少判断 | 头部只保留身份和连接；任务信息集中显示；输入 API Key 后可直接获取列表 | 浏览器验证首次配置无需先点保存，获取列表时只写入一次密钥，显示成功后输入框清空。 |
| 10 克制圆角阴影 | 去除阴影、装饰色边与悬浮装饰图案，统一面板和操作控件圆角 | 源码与截图检查通过。 |
