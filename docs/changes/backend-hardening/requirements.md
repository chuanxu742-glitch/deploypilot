# 需求与验收条件

授权与状态见 README.md。以下是 agent 根据修复授权与现有项目约定整理的验收条件，不冒充用户原话。

- B1：取消被观察到后，不再开始同批次剩余工具；文件操作错误能显示给操作员。
- B2：Windows 命令取消/超时终止其任务进程树；正常完成后刻意启动的后台服务可以保留。
- B3：HTTP 和 WebSocket 遵守同一服务端空闲期限；输入与有效任务输出续期，自动 ping/pong 不续期；过期/吊销关闭连接、取消任务。
- B4：整台客户端同一时间最多一个 AI 任务，包括断线后清理阶段；拒绝其他连接时明确返回可恢复状态。
- B5：未完成、损坏、长度截断、被过滤的模型响应不得执行工具或报告成功；已开始的流不能自动重放造成重复输出。
- B6：浏览器 Cookie 不早于服务端活动会话失效；服务端保留 30 分钟空闲失效的权威判断。
- B7：工具参数缺失/类型错误/未知字段/空路径/空命令/非法超时/空替换片段被拒绝；工具返回结果保持调用 ID 对应；finish 参数不完整不得结束任务。
- B8：长任务上下文有明确容量边界，保留系统约束、初始目标和完整调用/结果关系；压缩向操作员提示。若目标本身超限，明确失败，不静默截断任务目标。

不涉及：新工具种类、自动并行写操作、长期跨任务记忆、真实模型计费调用、隧道/安装器和前端重新设计、公开发布。
