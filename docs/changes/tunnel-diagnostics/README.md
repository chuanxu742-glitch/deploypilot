- 原始日志与本机代理快照放在 Git 忽略的 `.probe-tmp/tunnel-diagnostics/`，不把本机节点名、代理配置或凭证写进公开记录。
- 启动进度行会截断长文本，因此在原有日志改动之外，调整了入口重试输出，使用已有完整状态行后恢复进度；授权范围仍是底层错误的可见性。
- 正常网络握手尚未恢复，不关闭 issue；诊断修复已通过追加发布进入线上安装入口。
- 初次原命令验收受到测试辅助程序继承 PowerShell 7 模块路径的影响，Windows PowerShell 5.1 找不到 Get-FileHash。仅在测试子进程中移除继承的模块路径后，5.1 使用自身默认路径，命令恢复且完整安装验收通过；未修改系统配置或安装脚本。
