本文件将主人授权修复的报告第 1–8 项写成可核验行为；没有新增产品能力要求。

1. **历史请求顺序**：只应用用户最后一次仍有效的历史选择；新建、发送及后台切换任务应使先前历史响应失效，不能覆盖后来的视图或输入。
2. **发送确认与恢复**：同一网页中，发送到收到确认之间的断线不丢提交文本；以请求身份核对当前任务和历史摘要，确认已接受时不重发；无法确认时保存恢复入口，保留用户后来输入并明示不确定，晚到确认可以纠正状态。不会自动重发部署指令。
3. **认证恢复**：受保护 HTTP 接口明确返回 401、或 WebSocket 重连发现会话明确失效时，回到配对入口；网络失败、超时和其他未知状态不能直接当作认证过期。
4. **配对链接复访**：浏览器已有有效会话时，重新打开原始一次性配对链接仍可进入工作台；实际无效令牌、其他活动会话和网络问题应给出相符提示，不一律要求重启。
5. **草稿归属**：同一网页内按会话保存未发送草稿；切换历史再切回可以恢复，不因只读浏览或失败请求清空。恢复提交也必须带会话归属，不能载入其他任务并误发。
6. **状态归属**：全局任务是否运行/停止影响操作锁定；历史任务自身的 phase、结束时间只由有对应任务身份的状态更新，空闲通知不能改写旧历史。
7. **运行中输入语义**：运行中准备的是当前任务的补充消息，已有文字时仍能看见其归属；结束后用户明确发送，不自动排队。独立会话用“新建任务”。
8. **错误重试**：错误栏的重试对应当前失败动作，历史失败重试相同历史请求、模型失败重试模型状态；上下文改变后不保留能跳回旧任务的过期动作。

保留既有行为：IME 选词不发送，忙碌时 Enter 可换行；停止后清理完成前禁止重启；跨标签只允许一个后台任务；刷新/断线不取消已接受任务，不自动重发；续聊保留原记录身份与 user 消息；终端、主题与布局切换保持连接。
