# Agent 交互能力优化

状态与既有索引见本目录 README。本轮授权来自用户在18组缺陷修复回测报告后明确要求“那你优化啊”；接续原先参考 Codex 的交互目标，不再停留在审查建议。

## 目标与范围

1. 助手消息及总结支持安全 Markdown、列表、表格、链接、代码块精确复制；不执行回复里的 HTML、不自动加载外部图片。
2. 运行时可以只读浏览历史，明确返回活动会话，草稿和事件不串；旧会话可以按原任务ID继续，并在进程重启后恢复有效保存的上下文。既有无上下文旧记录允许明确标示的有界摘要恢复，不伪称完整恢复或旧验证仍有效。
3. 运行中可主动发送补充。后台区分接受、排队、应用和停止后未应用；请求编号去重，刷新/断线不自动重发，已接受消息不能被任务结束竞态吞掉，停止后不自动启动后续操作。
4. 桌面提供可切换的对话专注视图，扩大阅读和输入区域；终端保持挂载，恢复分栏时连接与输出保留。保留现有默认分栏和手机页签。

不做多任务并发、终端沙箱、认证/隧道/默认模型变更、系统软件安装、公共发布或用户已有实例重启。沿当前工作区保留前轮修复及所有原有未提交内容，不提交推送。

## 实施计划

没有独立 SDD；依照既有交互审查U1–U5及本次说明实施最小变更。使用 eri-flow 接续、eri-implementation 每片先测试再实现；收尾用 eri-comment-maintenance 和 eri-verification。

- 后端 agent：按任务保存有界、校验身份的私有会话状态，canContinue能力；新增有界运行补充队列和WS请求去重，Agent在安全执行边界消费，结束与停止和队列原子协调。主要改动agent、server及新增目标测试。
- 交互 agent：Agent/SessionSidebar/api/agent-state，忙时历史浏览、返回活动会话、明确续接、补充的发送/接受/应用与恢复；独立新CSS及浏览器回归，更新被本轮有意改变的旧测试假设。
- 内容 agent：成熟 Markdown 组件、独立样式、Timeline接入及依赖；GFM、复制、流式末尾、安全边界和手机浏览器回归。
- 主代理：App对话专注模式、文档和三路整合；核对源码和独立原始结果、构建最终资源，从真实网页入口验证历史/运行补充/终端保留，使用此前指定本机模型做限定无安装测试并归档清理。

每片定向红绿，不反复全仓测试。整合后执行前端单测/构建、既有20项任务交互和新增交互/内容/专注模式、相关Go测试及3项Go/Chrome联调；预计Go全包约40秒，在本机最终执行一次。真实模型只做本轮新能力场景，不重复整套部署压力或改变既有服务。

补充应用时机以实际后端消费边界为准，前端不提前写“已应用”；单任务槽一直持有到执行及清理结束。历史存储文件不含API配置或认证Cookie，使用私有原子写入；损坏或身份不匹配明确拒绝，不能静默开始新任务。

证据放本机忽略目录 `.probe-tmp/agent-ux-20261030/`。原始运行日志不回写；测试进程隔离用户目录和历史，使用随机本地端口；测试服务和运行文件归档后清理，保留不可可靠归属的用户混合历史。本轮不重试前轮被自动审批拒绝的空目录删除。
